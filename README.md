# Accounting Tracking — Receipts

Ảnh/PDF receipt của các expense đã ghi vào ClickUp (list "Accounting Tracking" / "Personal expense Tracking" của từng dự án).

- Mỗi dự án một folder, tên trùng tên list ClickUp, vd `4123 Accounting Tracking/`
- Tên file: `YYYY-MM-DD HHMM_Vendor.ext` (thời gian mua + tên chỗ mua)
- Receipt chụp nhiều ảnh được ghép thành 1 file PDF
